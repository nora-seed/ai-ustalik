# AI Ustalık 2026 — Çevrimdışı PWA Eğitim Uygulaması

2026 Küresel ve Türkiye Yapay Zeka Eğitim Ekosistemi raporuna göre hazırlanmış, sıfır derleme (Zero-Build), çevrimdışı çalışabilen (PWA) ve GitHub Pages uyumlu etkileşimli eğitim uygulaması.

## Özellikler
- **6 Mikro-Ders Modülü:** 5 Katmanlı Sistem Mimarisi, Bağlam & Harness Mühendisliği, %90/%10 Yönlendirme, MCP, Hibrit RAG, Evals, Ölümcül Üçlü & KVKK, Türkiye Ekosistemi.
- **SM-2 Aralıklı Tekrar (Spaced Repetition):** 26 kritik kavram kartı ile bilimsel kalıcılık.
- **Pratik Laboratuvar & 10 Senaryo Quizi:** Prompt Caching + Batch + Yönlendirme Maliyet Simülatörü, XML/`AGENTS.md`/`SKILL.md` Şablon Üretici, Ölümcül Üçlü Risk Denetçisi.
- **90 Günlük Yol Haritası:** Yazılım Geliştirici, Bilgi Çalışanı ve Yönetici kulvarları için somut çıktı (artifact) takibi.
- **Kaynak Kütüphanesi & Terimler Sözlüğü:** 38 küresel + Türkçe kaynak (8 yerli model dahil) ve 24 terimlik sözlük.
- **JSON Yedekleme & Koyu/Açık Tema:** Cihazlar arası veri taşıma ve tam çevrimdışı çalışma.

## GitHub Pages'te Yayınlama (1 Dakikada)
1. Bu `.zip` dosyasını önce bilgisayarınızda veya telefonunuzun Dosyalar uygulamasında **klasöre çıkarın (unzip)**.
   > Önemli: `.zip` dosyasının kendisini değil, **içindeki dosyaları** (`index.html`, `styles.css`, `data.js`, `app.js`, `manifest.json`, `sw.js` ve 3 `.png` ikon) doğrudan GitHub reponuzun ana dizinine yükleyin.
2. GitHub'da yeni bir **Public** repo oluşturun (ör. `ai-ustalik`).
3. **Add file → Upload files** ile çıkarılan tüm dosyaları yükleyip **Commit changes** deyin.
4. **Settings → Pages** bölümünde Source: `Deploy from a branch`, Branch: `main` / `/ (root)` seçip **Save** deyin.
5. 1–2 dakika içinde `https://kullanici-adiniz.github.io/ai-ustalik/` adresinden açılır.
6. iPhone Safari'de **Paylaş → Ana Ekrana Ekle**, Android Chrome'da **Uygulamayı Yükle** diyerek tam ekran çevrimdışı uygulama olarak kullanabilirsiniz.
